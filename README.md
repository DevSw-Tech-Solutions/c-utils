# C-Utils

C-Utils is a collection of useful tools designed to assist in any project developed in the C programming language. 
This project was created following the principles of Test-Driven Development (TDD) using the Ceedling framework.

## Features

- A collection of reusable utilities to optimize C development.
- Fully tested using automated tests to ensure reliability.
- Developed with a TDD approach for maintainability and robustness.
- Developed using Clean Code principles.
- Conventional Commits and Git Flow were used to work with Git.
- Semantical Versioning was adopted to identify releases versions.
